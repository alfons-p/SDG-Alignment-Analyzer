# Archived Scripts

This directory contains older or one-off scripts that are no longer actively used but kept for reference.

## Contents

- `examine_remaining_fragments.py` - Legacy script for examining text fragments
- `run_sdg_alignment_on_extracted.py` - Legacy script for running alignment on pre-extracted data

These scripts may be outdated and not compatible with current code. They are kept for:
- Historical reference
- Debugging old issues
- Recovering old approaches

Use at your own risk.
